DATABASE RS PERMATA ASRI

Untuk instalasi BARU, gunakan install_database.php dari browser.
File simrs_permata_asri.sql akan membuat database dasar dan installer kemudian melengkapi skema final.

Untuk database yang SUDAH BERISI DATA dari versi sebelumnya, jangan import ulang file SQL.
Gunakan update_database.php agar tabel/akun/fitur final ditambahkan tanpa menghapus data lama.
